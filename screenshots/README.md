### How to Capture Screenshots
- **Wokwi:** Use browser screenshot or the Windows Snipping Tool (Win + Shift + S). Ensure the simulation is running and the desired state is visible.
- **VS Code:** Take a screenshot of the editor with `main.cpp` or `config.h` open to show the codebase.
- **GitHub:** Navigate to the repository homepage and capture the layout, including the README.
